# 实习选岗系统 v1.0（单项目版）

## 简介
这是一个基于 Flask 的实习岗位选择系统，用于管理学生的实习岗位分配。

## 功能特性
- **管理员功能**：
  - 班级管理（添加/删除班级）
  - 学生管理（导入/删除学生）
  - 岗位管理（添加/编辑/删除岗位，设置配额）
  - 指定分配（手动指定学生到岗位）
  - 系统控制（开放/预览/关闭，定时开关）
  - 数据导入导出（Excel格式）
  
- **学生功能**：
  - 学号登录
  - 浏览可选岗位
  - 选择实习岗位
  - 查看分配结果

## 技术栈
- Python 3 + Flask
- SQLite 数据库
- Bootstrap 5 前端
- Gunicorn + Nginx 部署

## 快速开始
```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python app.py
```

## 部署
```bash
# 使用部署脚本
chmod +x deploy.sh
./deploy.sh
```
